# HTML 原型 V0.9 交付

## 已完成

- 固定透明导航与 JOEKUNI Logo；
- 2024《永劫无间》全屏视频首屏；
- 2023《永劫无间》第二个全屏 Statement 画面；
- 两段视频随页面自然滚动，正文独立固定在视口中央并交叉渐隐渐显；
- 两组正文按照滚动进度逐字出现，反向滚动时逐字消退；
- 每段正文逐字显示期间，对应视频固定在视口中；正文显示完成后，继续滚动才推动视频离开；
- 视频画面级放大裁切，去除原片内嵌的上下黑边；
- TVC、About、Contact 三个可访问锚点；
- 桌面、平板和手机的基础响应式结构；
- 视频静音、循环、内联播放、Poster、播放暂停和自动播放失败提示；
- 第二屏视频接近视口后才加载；
- 键盘焦点状态与 `prefers-reduced-motion` 支持。
- 直接访问锚点时正常定位；在 `#work`、`#about` 或 `#contact` 位置刷新时，地址恢复为主页并回到首屏顶部。
- 第二段视频分别使用由桌面版与移动版视频首个稳定画面生成的响应式 WebP Poster，不再共用旧 PNG。
- TVC 已按交付顺序加入 30 个作品项目，采用桌面 3 列、平板 2 列、手机 1 列的响应式网格。
- 每个作品分别生成桌面与移动端 WebP Poster，并使用首个稳定可见画面；内嵌黑边素材已在 Poster 中裁除。
- 本版本仅搭建作品页静态布局，不上传、不引用、不预加载作品视频，作品卡片暂不提供播放交互。
- 第二屏正文在视频固定阶段结束、画面开始向上划出时快速淡出，进入 Portfolio 前完全消失。
- 作品卡片的品牌名与类型名使用加粗字重，作品标题继续保持常规字重。
- TVC 标题使用加粗字重；作品区初始固定展示 4 行，桌面、平板、手机分别先显示 12、8、4 个项目，并可通过“查看更多／收起”展开或折叠。

## 浏览方法

在 `prototype` 目录启动任意静态网页服务器后访问 `index.html`。不建议直接双击文件，因为部分浏览器会限制本地文件的视频自动播放或媒体加载。

## 设计还原说明

按照 1440px 桌面稿实现双全屏影像、固定透明导航和左侧正文。两段视频按照正常页面流连续向上滚动；参考 DIVISION 的文字形式，正文独立固定在视口中央，只在两个视频的滚动交接区间切换透明度。设计稿中的放映机占位画面没有作为网页背景，已替换为交付文件指定的两段《永劫无间》素材。

## 响应式处理

移动端没有正式设计稿，当前采用单行紧凑导航、底部身份排版、流体字号和独立视频焦点位置。作品网格在桌面、平板和手机分别使用 3、2、1 列，并在 700px 断点切换到移动端 Poster。该处理属于技术原型假设，需在移动端设计稿确认后复核。

## 视频与性能说明

当前直接加载交付的 68MB 和 25MB 原片副本，仅用于本地视觉验证，不可作为正式上线方案。首屏只预加载 metadata；第二段视频在滚动接近交接区域后才加载。视频统一放大裁切约 1.34 倍以去除上下黑边，代价是左右画面会被进一步裁去；移动端暂用约 1.4 倍。正式阶段应直接输出无黑边的 6–12 秒循环版，并分别准备桌面、移动端编码及正式 Poster。

## 当前占位内容

作品视频播放、个人介绍与联系方式暂未接入；没有公开未确认的私人信息。

## 已知问题

- 汇文明朝体和钉钉进步体未随交付文件提供，当前使用系统字体回退；
- 作品 Poster 已从交付视频筛选生成，但仍需在最终视频接入后复核 Poster 到起播画面的切换；
- 不同浏览器的视频裁切焦点尚需真实画面复核；
- 当前渐隐渐显以整组正文为单位，尚未拆成逐行时间线。
- 放大裁掉黑边后，部分横向画面会被裁去，仍需按最终镜头确定每段视频的焦点位置。
