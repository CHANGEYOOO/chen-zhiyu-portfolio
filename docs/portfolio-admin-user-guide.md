# 作品管理后台操作指南

> 适用版本：responsive portfolio admin workbench（2026-08-02）  
> 面向用户：授权管理员，通过桌面或手机浏览器操作  
> 说明：本指南仅记录后台工作台操作流程，不涉及服务端密钥、管理员邮箱或内部 API 路径

## 1. 进入管理后台

1. 使用浏览器打开 `https://kjoe.top/admin/`。
2. 在 Cloudflare Access 登录页面填写管理员邮箱，点击“Send login code”。
3. 输入收到的六位一次性验证码，进入内容工作台。

登录后页面顶部会显示当前邮箱与“退出登录”按钮。

## 2. 工作台概览

- **桌面端（≥1024px）**：左侧为作品列表，右侧为编辑面板，底部浮层为上传队列。
- **手机端（<1024px）**：列表与编辑器为单栏切换布局，底部固定栏提供“返回列表”“保存”“预览”“发布”按钮。

### 筛选与搜索

- 按栏目筛选：“全部”“TVC”“直播间”。
- 按状态筛选：“全部状态”“草稿”“已发布”“已归档”。
- 搜索框支持输入品牌名、作品名称或类型关键字。

每行作品卡片显示缩略图、名称、状态标签，并标注材料缺失项（如“缺：海报、视频”）。

## 3. 新增 TVC 作品

操作顺序：

1. 点击列表上方“新增 TVC”按钮，编辑器打开。
2. **填写文字字段**：
   - 栏目（固定 TVC）；
   - 排序（数字，越小越靠前）；
   - 品牌名；
   - 作品名称 / 影片名（必填）；
   - 作品类型（必填）。
3. **保存草稿**：点击“保存文字”按钮，提交到远端并刷新列表。
4. **添加封面**：在“上传封面原图”字段选择本地图片（支持 WebP、JPEG、PNG）。选择后封面区域即显示预览，远端自动生成 1600×900 与 960×540 两张 WebP 变体。
5. **添加视频**：在“上传影片”字段选择本地视频（MP4 或 WebM）。大文件自动分片上传，进度在底部上传队列中显示。
6. **发布前检查**：点击“预览”查看作品前台展示效果（只读面板）。
7. **发布**：点击“发布”按钮，系统会先检查必填项：
   - 出版名前、作品名称、作品类型是否为空；
   - 封面是否已上传；
   - 视频是否已上传。
   - 如有缺失项，发布按钮旁边会显示提示；满足全部条件后方可发布。
8. 确认发布弹窗会显示作品名称和变更摘要（如“品牌：— → 网易”）。点击“确认发布”生效。

## 4. 新增 Livestream 作品

操作顺序：

1. 点击列表上方“新增直播间”按钮。
2. **填写文字字段**：
   - 栏目（固定 直播间）；
   - 排序；
   - 作品名称 / 直播名（必填）；
   - 类型（必填）。
3. **保存草稿**。
4. **管理项目图片**（数量不设上限）：
   - 点击“添加项目图片”选择本地多张图片；
   - 图片列表显示每张缩略图与文件名；
   - **拖拽排序**：长按或鼠标按住拖拽手柄，拖动到目标位置松开；
   - **键盘排序**：选中拖拽手柄后使用上下方向键移动当前行；
   - **按钮排序**：点击每行右侧的上/下箭头按钮移动；
   - 排序后需点击“保存排序”，图片位置即提交到远端；
   - 也可点击“取消排序”放弃本次排序改动；
   - 第一张图片自动成为前台封面（列表内标注“封面”）。
5. **发布前检查**：点击“预览”查看只读效果，包括封面、作品信息与完整图片画廊。
6. **发布**：点击“发布”，系统检查必填项与项目图片是否添加。满足后弹出确认，点击“确认发布”。

## 5. 预览面板

- 预览面板为**只读**，展示作品在前台将如何呈现。
- TVC 预览：封面图片、视频播放器、作品元信息（品牌 · 类型）。
- Livestream 预览：第一张封面图标注“封面”，下方依次展示全部项目图片。
- 关闭方式：点击右上角“×”、按 Escape 键或点击面板外区域。

## 6. 发布与生命周期管理

### 发布确认

点击“发布”后弹出自定义确认面板，内容包括：
- 作品名称；
- 变更摘要（各字段的新旧值对比，无文字变更时显示“没有文字变更”）。
- 点击“确认发布”后，作品状态变为“已发布”并同步显示在前台。

### 取消发布

- 已发布作品可点击“取消发布”退回草稿状态。
- 确认面板提示“将回到草稿状态，不再显示在前台”。
- 点击“确认取消发布”后生效。

### 归档与恢复

- **归档**：将作品标记为“已归档”，同时从前台隐藏。确认面板提示“可在『已归档』筛选下恢复”。
- **恢复**：在状态筛选切换至“已归档”后可见归档作品列表，点击“恢复”将作品回到草稿状态，可继续编辑后重新发布。

以上每一项操作均需在自定义确认面板中明确确认后方可执行。

## 7. 上传管理

### 上传队列

编辑器底部有上传摘要条，显示当前上传任务数。点击“打开上传队列”展开上传抽屉面板。

### 队列操作

- **暂停全部**：暂停所有正在进行的上传任务。
- **继续全部**：恢复已暂停的上传任务。
- **重试全部**：重试失败的上传任务。
- **取消全部**：取消所有待处理和进行中的上传任务。

### 单文件操作

队列中每个上传条目显示文件名、目标作品、文件大小与进度条。单文件支持：
- **暂停**：暂停当前文件上传。
- **继续**：从中断位置恢复上传（分片续传）。
- **重试**：失败后重新上传。
- **取消**：删除该上传任务并清理远端已上传分片。

### 网络断线恢复

- 设备离线时，上传管理器自动检测网络状态并显示“等待网络恢复”。
- 恢复在线后，已开始的分片上传可从中断位置继续（localStorage 保存了上传会话）；未开始的上传需手动点击“重试”。
- 页面意外关闭或刷新后，恢复记录保存在浏览器中，重新进入同一作品的编辑器时会提示可恢复的上传。

### iOS 注意事项

iOS Safari 在后台或锁屏时可能暂停网页运行，导致上传中断。建议上传大文件时保持浏览器前台、设备不息屏。

## 8. 草稿保存

- “保存文字”按钮立即将当前表单的文字内容提交到远端。
- 同时表单内容自动存入浏览器 localStorage，关闭页面或切换作品后可恢复未提交的文字。
- 媒体文件（图片、视频）不存入 localStorage，需重新选择后上传。

## 9. 编辑已有作品

1. 在作品列表中点击任一作品卡片，编辑器打开并加载当前内容。
2. 修改文字后点击“保存文字”。
3. 替换或新增封面/视频/项目图片。
4. 点击“预览”检查效果。
5. 按需执行发布、取消发布或归档操作。

编辑过程中底部上传队列独立运行，不影响其他作品的上传进度。

## 10. 安全与边界

- 管理后台通过 Cloudflare Access 邮箱验证码保护，仅授权邮箱可进入。
- API 路由同样受 Access 保护，未登录请求返回 302 重定向至登录页。
- 本指南不记录 Worker 密钥、管理员邮箱地址或内部 API 路径。
- 后台不提供物理删除功能；作品仅可在草稿、已发布、已归档三个状态之间流转。
